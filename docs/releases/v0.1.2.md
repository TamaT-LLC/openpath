# v0.1.2

`v0.1.2` は、openpath 専用のアプリアイコンを追加するリリースである。
Stable の tag、GitHub Release、添付の `SHA256SUMS` がそろったときに、正式版として扱う。
次の版に入る変更は [未リリースの変更](./unreleased.md) に記録する。

## 変更

- 青いフォルダと白い矢印を組み合わせたアプリアイコンを追加した。Finder やシステムのアプリ一覧で openpath を見分けやすくする。
- 配布するアプリに、16〜1024 ピクセルの画像を含む `AppIcon.icns` を同梱する。
- 元の透過 PNG、画像生成プロンプト、macOS の標準ツールで `.icns` を再生成する `scripts/build-icon.sh` を追加した。

## 確認範囲

ファイル選択パネルの検知、検索、キー入力、権限、ネットワーク通信は変更していない。
実機で未確認の既存項目は [v0.1.1 のリリースノート](./v0.1.1.md) を参照する。
アイコンの配布 ZIP での確認結果は GitHub Release に記録する。
