# v0.1.2（アプリアイコンの追加）

`v0.1.2` は、openpath 専用のアプリアイコンを追加するリリースである。
Preview `preview-v0.1.2-1` の配布 ZIP を実機で確かめ、同じコミットから Stable を公開した。
公開は 2026-10-05 で、GitHub Release の添付は `openpath-0.1.2.zip`、`SHA256SUMS`、`openpath.rb` である。
次の版に入る変更は [未リリースの変更](./unreleased.md) に記録する。

## 変更

- 青いフォルダと白い矢印を組み合わせたアプリアイコンを追加した。Finder やシステムのアプリ一覧で openpath を見分けやすくする。
- 配布するアプリに、16〜1024 ピクセルの画像を含む `AppIcon.icns` を同梱する。
- 元の透過 PNG、画像生成プロンプト、macOS の標準ツールで `.icns` を再生成する `scripts/build-icon.sh` を追加した。

## 確認範囲

ファイル選択パネルの検知、検索、キー入力、権限、ネットワーク通信は変更していない。
実機で未確認の既存項目は [v0.1.1 のリリースノート](./v0.1.1.md) を参照する。

## 公開前に実機で確かめたこと

- 2026-10-05: Preview `preview-v0.1.2-1` の配布 ZIP。環境は macOS 27.0。Finder のアイコンとプレビューを確かめた。

正式版は Preview と同じコミットから生成し、ダウンロードした Stable の成果物で次を検証した。

- ZIP と cask の `SHA256SUMS`
- Developer ID 署名
- Gatekeeper の評価（Notarized Developer ID）と公証チケット
- arm64 / x86_64 の構成
- 同梱した `AppIcon.icns` の一致

Release CI の Swift Testing は 1,867 件が成功している。
自動テストの成功を、実機で確かめたこととは扱わない。
