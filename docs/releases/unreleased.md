# 未リリースの変更

次の版に入る変更を記録する。
`v0.1.3` の内容は [v0.1.3 のリリースノート](./v0.1.3.md) にある。
Stable のタグは Preview と同じコミットに付けるので、Preview を作る前に、このファイルを `vX.Y.Z.md` に改めて 1 行目を `# vX.Y.Z` または `# vX.Y.Z（補足）` にし、新しい `unreleased.md` を作る。
続けて `python3 scripts/release_notes_index.py` で [ドキュメントインデックス](../00_index/index.md) のリリースノート一覧を作り直す（CI が `--check` で検査する）。

## 変更

- 保存ダイアログで保存先フォルダを検索して移動できるようにした。入力済みのファイル名・拡張子を保持し、`auto_confirm` / Cmd+Enter でも保存は自動確定しない。移動先シートを送信直前に確認できなければ Return を送らず中断する（#134）。

- フォルダ候補で Tab を押すと、その直下を読み込んで検索できるようにした。設定した走査の深さを超えて、Tab を繰り返して深い階層へ進める。読み込み中・空・アクセス不可・不存在の案内を分け、パレットを閉じると取得した候補を破棄する（#132）。
