# v0.1.3（候補行のフォルダ・書類アイコン）

`v0.1.3` は、パレットの候補行にフォルダ・書類のアイコンを表示するパッチリリースである。
選択中の行はアイコンを塗りつぶし、候補の種類と選択状態を見分けやすくする。
次の版に入る変更は [未リリースの変更](./unreleased.md) に記録する。

## 変更

- パレットの候補行の三角マーカーを、フォルダ・書類のアイコンに変更した（#128）。各行にアイコンを表示し、選択行では塗りつぶす。

## 配布と開発環境の変更

- README の「検索」まわりの説明から、`cdr` や `fzf` を引き合いに出す表現を外した（#123）。UX 設計、プロダクト概要、ドキュメントインデックスの題も合わせた。
- `FileListRowSampler` と `FileListSample` のテストで、パラメータ化テストの引数の配列に型注釈（`as [(String, String, Int)]` など）を付けた（#123）。テストの内容は変えていない。
- README.md に約35秒の日本語版の紹介動画を追加した（#124）。README.en.md には約34秒の英語版を追加した（#125）。GitHub の動画添付を使い、README 上で再生できるようにした。
- ドキュメントインデックスのリリースノート一覧を自動生成するようにした（#126）。CI で一覧と `docs/releases/` の一致を検査する。
- 署名・公証の認証情報を GitHub environment `release` に移した（#127）。Homebrew tap 更新用の認証情報は `homebrew-tap` に移し、それぞれ利用できるタグやブランチを限定した。
- Stable と Preview のタグを作れるアカウントを admin に限定した（#127）。公開済みタグの更新・削除は、引き続き admin を含め誰にも許可しない。

## 確認範囲

パレットのネイティブプレビューで、ライト・ダーク、フォルダ・書類、選択時の塗りつぶしを確認した。
検索結果の順位、パネルの検知、パスの入力、求める権限は変更していない。
本体アプリとファイル選択パネルを通した手動シナリオは未確認である。

## 実機で確かめる項目

配布する Preview の ZIP から起動し、候補行の表示と選択を確かめる。

[v0.1.1 のリリースノート](./v0.1.1.md) の「実機で確かめていない項目」を引き継ぐ。
