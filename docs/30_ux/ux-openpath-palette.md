# UX 設計: openpath パレット（cdr 風の使用感）

## 1. 体験の原則

1. **ゼロ操作で出る**: パネルが出たら勝手にパレットが重なる。ホットキーは「再表示」のためだけにある。
2. **ターミナルの指癖で動く**: fzf / cdr と同じキー（Ctrl+N/P、Enter、Esc）で完結する。
3. **パネルを壊さない**: パレットは常にオプション。Esc で消せば元の NSOpenPanel がそのまま使える。
4. **確定はユーザーの手で**: 既定では「パネルを目的地に移動させる」までで止め、最後の Enter はユーザーに委ねる（誤爆防止）。

## 2. 基本フロー

```
[アプリ] フォルダを開く
   │
   ▼
[NSOpenPanel] 表示 ──(検知 ≤300ms)──▶ [openpath パレット] パネル右上に重ねて表示
                                          │  frecency 上位 8 件を初期表示
                                          │  ユーザーが 2〜5 文字タイプ
                                          │  ↑↓ / Ctrl+N/P で選択
                                          ▼
                                       Enter で確定
                                          │
                                          ▼
[NSOpenPanel] Cmd+Shift+G → パス入力 → 移動完了（パレットは閉じる）
   │
   ▼
ユーザーが Enter（または「開く」）で確定 ※auto_confirm=true なら自動
```

## 3. パレットのレイアウト

```
┌───────────────────────────────────────────────┐
│ 🔍 fern                                        │  ← 検索フィールド（常にフォーカス）
├───────────────────────────────────────────────┤
│ ▶ fern                    ~/repos/…/TamaT-LLC │  3分前
│   fern-docs               ~/repos/…/TamaT-LLC │  2日前
│   fernet-config           ~/dev/misc          │  3週間前
│                                               │
├───────────────────────────────────────────────┤
│ ↑↓ 選択  ⏎ 移動  ⌘⏎ 移動して開く  esc 閉じる   │  ← フッター（ヒント）
└───────────────────────────────────────────────┘
```

- 幅 560pt、行高 28pt、最大 8 行。パネルの右上角に 12pt オフセットで配置。パネルが画面右端に近い場合は左上に配置。
- 表示名はディレクトリ名（ファイルの場合はファイル名）。パスは中央省略（`…`）で 1 行に収める。
- マッチ文字はハイライト（アクセントカラー、太字）。
- 最終使用日時は相対表記（「3分前」「2日前」）。履歴にない候補は空欄。

## 4. キーバインド

| キー | 動作 |
| --- | --- |
| 文字入力 | インクリメンタル検索（IME 変換中はマッチ更新を保留） |
| ↑ / ↓、Ctrl+P / Ctrl+N | 候補選択 |
| Enter | 選択候補へパネルを移動（auto_confirm 設定に従う） |
| Cmd+Enter | 選択候補へ移動し、そのまま「開く」を押す（設定に関わらず自動確定） |
| Tab | 選択候補のパスを検索フィールドに展開（サブディレクトリを掘る） |
| Esc | パレットを閉じる。NSOpenPanel はそのまま残る |
| Ctrl+Shift+O（既定ホットキー） | パレットを再表示 |

## 5. 状態と表示

| 状態 | 表示 |
| --- | --- |
| 候補ソース構築中 | フッターに「候補を構築中…」。履歴分は即時表示 |
| 候補 0 件 | 「一致する候補がありません。Tab でパスを直接入力」 |
| 注入中 | フッターに「パネルへ移動中…」、入力を一時ロック（最大 1.5 秒） |
| 注入失敗 | フッターに赤字で「移動できませんでした（⌘⇧G が開きません）」。パレットは残す |
| アクセシビリティ権限なし | パレットは出さず、メニューバーアイコンにバッジ。クリックで権限設定を案内 |

## 6. メニューバー

```
● openpath
  ├ 有効（チェック切替）
  ├ 候補を再構築
  ├ 設定ファイルを開く…
  ├ 履歴をクリア…
  ├ ログイン時に起動
  ├ アクセシビリティ設定を開く…（未付与時のみ）
  └ 終了
```

## 7. 初回起動

1. アクセシビリティ権限の説明ダイアログ（何のために使うかを 3 行で説明）→ システム設定を開く。
2. 権限付与後、`~/.config/openpath/config.toml` を既定値で生成（ghq root が見つかれば自動で `roots` に追加）。
3. 「試してみる」ボタンで Finder の「開く」ダイアログを起動し、動作を体験させる。

## 8. アンチパターン（やらないこと）

- パレット表示時に NSOpenPanel からフォーカスを奪う（ユーザーの手打ちを妨げる）。
- 既定で自動確定する（誤ったフォルダを開いてしまう）。
- パネル以外のダイアログ（アラート、保存ダイアログ）に反応する。
