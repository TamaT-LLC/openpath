# UX 設計: openpath パレット（cdr 風の使用感）

## 1. 体験の原則

1. **ゼロ操作で出る**: パネルが出たら勝手にパレットが重なる。ホットキーは「再表示」のためだけにある。
2. **ターミナルの指癖で動く**: fzf / cdr と同じキー（Ctrl+N/P、Enter、Esc）で完結する。
3. **パネルを壊さない**: パレットは常にオプション。Esc で消せば元の NSOpenPanel がそのまま使える。
4. **確定はユーザーの手で**: 既定では「パネルを目的地に移動させる」までで止め、最後の Enter はユーザーに委ねる（誤爆防止）。

## 2. 基本フロー

```
[アプリ] フォルダを開く
   │
   ▼
[NSOpenPanel] 表示 ──(検知 ≤300ms)──▶ [openpath パレット] パネル右上に重ねて表示
                                          │  frecency 上位 8 件を初期表示
                                          │  ユーザーが 2〜5 文字タイプ
                                          │  ↑↓ / Ctrl+N/P で選択
                                          ▼
                                       Enter で確定
                                          │
                                          ▼
[NSOpenPanel] Cmd+Shift+G → パス入力 → 移動完了（パレットは閉じる）
   │
   ▼
ユーザーが Enter（または「開く」）で確定 ※auto_confirm=true なら自動
```

## 3. パレットのレイアウト

```
┌───────────────────────────────────────────────┐
│ 🔍 fern                                        │  ← 検索フィールド（常にフォーカス）
├───────────────────────────────────────────────┤
│ ▶ fern                    ~/repos/…/TamaT-LLC │  3分前
│   fern-docs               ~/repos/…/TamaT-LLC │  2日前
│   fernet-config           ~/dev/misc          │  3週間前
│                                               │
├───────────────────────────────────────────────┤
│ ↑↓ 選択  ⏎ 移動  ⌘⏎ 移動して開く  esc 閉じる   │  ← フッター（ヒント）
└───────────────────────────────────────────────┘
```

- 幅 560pt、行高 28pt、最大 8 行、候補 0 件でも 1 行分の高さを確保する（`minVisibleRowCount = 1`。§5 の案内表示に使う、PR #38）。
- 配置: パネルの右上角から内側へ 12pt（右へ -12pt、下へ 12pt）ずらした位置にパレットの右上角を重ねる（`PaletteMetrics` で一元管理。外側へ張り出す解釈もあり得るため明示、PR #38）。パレットの右端が画面の可視領域（メニューバー / Dock を除く）の右端を超える場合は左上配置（`minX = panel.minX + 12`）に切り替える。最後に可視領域へクランプする。
- level は `.modalPanel + 1`（NSOpenPanel の runModal 中の level を実測すると 8 = `.modalPanel` だったため。`.floating` では背面に回る一方、`.popUpMenu` より下なのでパネルのポップアップメニューはパレットより前面に出る、PR #38）。
- 検索フィールド高 44pt・フッター高 28pt は本ドキュメントに指定が無いため実装時点の仮値（`PaletteMetrics`）。見た目を確認した上で変更していない（PR #38 / #44）。
- 表示名はディレクトリ名（ファイルの場合はファイル名。列は固定幅 180pt、収まらない場合は末尾を省略）。場所の列（候補の親ディレクトリ）を別に表示し、行ごとに開始位置を揃える。パスの中央省略はディレクトリ単位で行い、先頭（`~` またはルート）と末尾の要素は必ず残す（PR #44）。
- マッチ文字はハイライト（アクセントカラー、太字）。省略記号（`~` / `…`）に隠れた位置のマッチもハイライトする。
- 最終使用日時は相対表記（「3分前」「2日前」）。履歴にない候補は空欄。
- 選択行の背景はシステムカラー `unemphasizedSelectedContentBackgroundColor`（アクセントカラーで塗るとマッチのハイライトが見えなくなるため、PR #44）。

## 4. キーバインド

| キー | 動作 |
| --- | --- |
| 文字入力 | インクリメンタル検索（IME 変換中はマッチ更新を保留） |
| ↑ / ↓、Ctrl+P / Ctrl+N | 候補選択（端で止まり循環しない。リピートでも移動を続ける） |
| Enter | 選択候補へパネルを移動（auto_confirm 設定に従う） |
| Cmd+Enter | 選択候補へ移動し、そのまま「開く」を押す（設定に関わらず自動確定） |
| Tab | 選択候補のパスを検索フィールドに展開（サブディレクトリを掘る。候補 0 件では何もしない） |
| Cmd+Z | Tab による展開を取り消す（UX-001 の当初案にはない追加、PR #49） |
| Cmd+V 等の標準編集ショートカット | 検索フィールドへの貼り付け・カット・コピー・全選択等（当初案にはない追加。openpath はメインメニューを持たないため、キー処理からこれらを送る。パスを貼り付けて探す用途を想定、PR #49） |
| Esc | パレットを閉じる（検索語と選択は保持）。NSOpenPanel はそのまま残る |
| Ctrl+Shift+O（既定ホットキー） | パレットを再表示 |

- Enter / Esc / Tab は、割り当てのない修飾やキーリピートでも消費する（検索フィールドに渡すと編集終了・補完ポップアップ・フォーカス移動が起きるため）。テンキーの Enter（0x4C）は Return の代替として対応していない（PR #49）。
- Ctrl+N/P と編集ショートカットは基本的に入力文字で判定するが、文字が取れないキー（配列によって記号が変わる等）は US 配列の物理位置で判定する（fzf と同様、PR #49）。
- Tab の展開は候補の絶対パス（`~` に縮めない）を使う。展開先がディレクトリなら末尾に `/` を付け、そのディレクトリ自身は候補から除外する。

## 5. 状態と表示

| 状態 | 表示 |
| --- | --- |
| 候補ソース構築中 | フッターに「候補を構築中…」。履歴分は即時表示 |
| 候補 0 件 | **リスト領域**に「一致する候補がありません。Tab でパスを直接入力」（フッターではなく候補行と同じ領域に表示する。構築中の表示と同時に出せるため、PR #44） |
| 注入中 | フッターに「パネルへ移動中…」、入力を一時ロック（最大 1.5 秒） |
| 注入失敗 | フッターに赤字でエラーを表示（DSN-001 §3.3 の文言。「⌘⇧G が開きません」等）。1.5 秒タイムアウトと `panelGone` を除き、パレットは PanelShown に戻って残る（Esc または `panelGone` で閉じる、ARCH-001 §5・PR #39） |
| アクセシビリティ権限なし | パレットは出さず、メニューバーアイコンにバッジ。クリックで権限設定を案内 |

- フッターに出す情報は 1 つだけ（560pt に収まらないため）。優先順は エラー・状態表示 > 構築中 > キーヒント（PR #44）。
- 「候補を構築中…」は起動後最初の全件構築の間だけ表示する。5 分ごとの周期の再構築や手動の再構築ではフッターを切り替えない（表示中のパレットがちらつくのを避けるため、PR #63）。
- 検索語が `/` または `~/` で始まり、存在するパスなら候補の先頭に直接入力の行が出る（フォルダ選択のパネルではディレクトリのみ）。Enter でそのまま移動でき、Tab で `パス/` に展開すると配下を絞り込める。末尾に `/` を打つと直接入力の行は消える（展開した直後は配下を掘っている途中とみなすため）。文言「Tab でパスを直接入力」は Tab の操作を必須であるかのように読めるが、実際は入力するだけで候補に出る。文言の変更は `Sources/` 側の実装を伴うため本ドキュメント更新では行わず、レビュー用 PR に提案として記載する（PR #65）。

## 6. メニューバー

```
● openpath
  ├ （権限未付与 / 設定エラー時のみ）通知。クリックで案内
  │   権限なし → アクセシビリティ設定を開く / 設定エラー → 設定ファイルを開く
  ├ ─────────────
  ├ 有効（チェック切替）
  ├ 候補を再構築
  ├ 設定ファイルを開く…
  ├ 履歴をクリア…
  ├ ─────────────
  ├ ログイン時に起動（`.app` として起動していないとグレーアウト）
  ├ アクセシビリティ設定を開く…（未付与時のみ）
  └ 終了
```

- 先頭の通知はメニューを開くたびに状態を読み直し、選べる項目にした（クリックで権限設定または設定ファイルを開く。説明は 320pt に自前で改行する、PR #55）。権限なし → 設定エラー → クリップボードの復元失敗の順に並べ、無い通知は省く（PR #65）。
- 「有効（チェック切替）」は起動のたびに有効から始まる。設定ファイルには書き戻さず永続化しない（一時的に止める用途を想定。永続化の要否はオーナー判断待ち、PR #65）。無効の間もパネルの監視とホットキーは止めるが、候補の構築は続ける。
- 「履歴をクリア…」で履歴ファイルへの保存に失敗した場合はダイアログで知らせる（候補からは消えているが、保存できないまま終了すると次の起動で元の履歴に戻り得るため、PR #65）。
- 自動確定でパネルが閉じた後にペーストボードを元へ戻せなかった場合、通知「クリップボードを元に戻せませんでした」をバッジ付きで出す。選ぶと通知は消える（PR #65）。
- メニューはグループごとに区切り線を入れる。
- バッジはテンプレート画像の右上をくり抜いて点を置く（色付きの点だとテンプレート画像にできず、ライト / ダーク追従が崩れるため、PR #55）。
- 「ログイン時に起動」は `SMAppService.mainApp` が `.app` バンドルの登録を前提とするため、`swift run` 等バンドル外では機能しない。その場合はグレーアウトし、ツールチップで「openpath.app として起動したときだけ設定できます」と伝える（PR #55）。

## 7. 初回起動

1. アクセシビリティ権限の説明ダイアログ（何のために使うかを 3 行で説明）→ システム設定を開く。
2. 権限付与後、`~/.config/openpath/config.toml` を既定値で生成（ghq root が見つかれば自動で `roots` に追加）。
3. 「試してみる」ボタンで Finder の「開く」ダイアログを起動し、動作を体験させる。

## 8. アンチパターン（やらないこと）

- パレット表示時に NSOpenPanel からフォーカスを奪う（ユーザーの手打ちを妨げる）。
- 既定で自動確定する（誤ったフォルダを開いてしまう）。
- パネル以外のダイアログ（アラート、保存ダイアログ）に反応する。
